# Comandos

## 1. Entrar a la carpeta
```bash
cd Proyecto-Regresion-Casas-Streamlit
```

## 2. Instalar dependencias
```bash
pip install "scikit-learn==1.5.2" "feature-engine==1.8.2" pandas joblib streamlit matplotlib
```

## 3. Lanzar la app
```bash
streamlit run modelo_ml_streamlit.py
```
Abrir: http://localhost:8501

## 4. Probar
Subir `Proyectos-ML-CookieCutter/proyecto_regresion_casas/data/raw/test.csv` y dar clic en el botón.
